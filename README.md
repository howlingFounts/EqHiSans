# 嗷呜等高体

嗷呜等高体是一款**商用免费**的汉字和西文（大写字母、数字）等高的字体，基于《[Roboto Flex](https://github.com/googlefonts/roboto-flex)》和《[文渊黑体](https://github.com/takushun-wu/WenYuanFonts)》，旨在方便食品饮料包装等需要汉字和西文等高的场景。

## 授权信息

本字体使用 [SIL OFL 1.1](OFL.txt) 许可证，商用免费，可自由传播，允许嵌入，允许在本字体基础上制作二创字体。

二创字体需同样遵守 [SIL OFL 1.1](https://openfontlicense.org/open-font-license-official-text/) 许可证。
