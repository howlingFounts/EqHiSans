# 嗷呜等高体

**商用免费**的汉字和西文（大写字母、数字）等高的字体，基于《[Roboto Flex](https://github.com/googlefonts/roboto-flex)》和《[文渊黑体](https://github.com/takushun-wu/WenYuanFonts)》，旨在方便商品标签等需要汉字和西文等高的场景。

2025 年，某字体企业和设计工作室发布了一套包装用的黑体，该字体汉字和西文（大写字母、数字）等高，并支持窄体。然而，其授权费用不菲（按单一包装需 ¥ 2700，按一个公司下全部品牌和产品线的包装更需要 ¥ 129600 或者每年 ¥ 21600），而国内不少企业目前都在“降本增效”，很多公司宁愿其美工辛苦地手动调整西文字高、把文字机械压缩，也不愿花额外成本购买该字体的授权。《嗷呜等高体》基于开源字体进一步修改，实现汉字西文等高以及窄体，支持可变，方便商品标签等场景，节省美工调整时间，还能节省金钱成本！
